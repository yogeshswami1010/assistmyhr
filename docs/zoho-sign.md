# Zoho Sign for offer letters

1. Create a Zoho OAuth client in the same data center as your Zoho Sign organization. Generate an offline refresh token with `ZohoSign.documents.CREATE,ZohoSign.documents.READ,ZohoSign.documents.UPDATE`. Set the client ID, secret, refresh token, and regional suffix (for example, `in` for `sign.zoho.in`) in the ATS server environment. [Zoho OAuth setup](https://www.zoho.com/sign/api/oauth.html) · [Zoho data centers](https://www.zoho.com/sign/api/api-endpoint.html)
2. In SaaS mode set `ZOHO_SIGN_WORKSPACE` to the slug of the workspace that owns this Zoho Sign account. This deployment configuration connects one workspace to one account. Run `php artisan migrate --force`, then `php artisan saas:migrate --force` for SaaS deployments. Refresh the Laravel configuration cache.
3. Set `ZOHO_SIGN_WEBHOOK_SECRET` and register the ATS HTTPS endpoint `/zoho-sign-webhook` in Zoho Sign's API settings. In SaaS mode append `?workspace=your-workspace-slug`. Enable HMAC using the same secret and subscribe to completion, decline, recall, and expiration. Recruiters can also use **Refresh status** in **Document Sign**. [Zoho webhook security](https://help.zoho.com/portal/en/kb/zoho-sign/admin-guide/webhooks/articles/securing-zoho-sign-webhooks-with-hmac-authentication)
4. Upload a text-based offer PDF with `{{Signature}}` where the candidate should sign. Open **Document Sign** from the ATS sidebar, select the offer and PDF, and save the signing method. Send the ATS offer link from Onboarding. [Zoho signature tags](https://help.zoho.com/portal/en/kb/zoho-sign/user-guide/sending-a-document/articles/automatic-field-addition-in-zoho-sign)
5. The candidate opens the ATS link and submits any onboarding answers to receive the Zoho signing email. Once Zoho confirms completion, the ATS marks the offer accepted. Use **Download signed PDF** in **Document Sign** to retrieve the signed letter and completion certificate. Recall an active request in Zoho Sign to cancel it.

For a trial with your own test recipient, set `ZOHO_SIGN_TESTING=true`. Zoho applies a permanent test watermark to documents sent in this mode. [Zoho API testing](https://www.zoho.com/sign/api/getting-started-with-zoho-sign-api.html)
